# Ежедневная сводка: первый пользовательский результат

**Статус:** спецификация, без расписания и запуска на реальных сообщениях.

## Вход и выпуск

- Период — календарные сутки по `Europe/Moscow`; в выпуске указан точный
  диапазон времени и момент готовности индекса.
- Целевой охват — весь доступный архив личного Telegram, включая каналы,
  группы и личные диалоги. Настройку исключений можно добавить позже;
  исключения не подразумеваются молча.
- Первый формат — локальный Markdown-черновик. Автоматическая отправка в
  Telegram, почту или другой сервис не входит в первый выпуск.

## Структура

1. Краткая общая картина дня: несколько наиболее значимых сюжетов, а не
   перечень всех сообщений.
2. По каждому сюжету: что произошло, чем это подтверждено, ссылки на
   исходные сообщения из разных чатов, если сюжет повторялся. Для приватного
   чата без публичного URL ссылка открывает оригинал через tgcli.
3. Новые вопросы или расхождения, которые нельзя уверенно разрешить по
   источникам.
4. Покрытие: сколько чатов и сообщений вошло в период, какие источники
   неполны или недоступны. Числа не заменяют проверку содержания.

## Правила качества

- Существенные утверждения должны иметь проверяемые ссылки на оригиналы.
- Повторы и пересылки объединяются, но сохраняют отдельные источники.
- Более поздняя правка или удаление сообщения меняет либо отзывает вывод.
- При недостатке данных выпуск обозначается частичным. Модель не дополняет
  пробелы догадками.
- Отдельно проверяются фактическая точность, полезность отбора, пропуски
  важных событий и стоимость обработки. До оценки используются только
  синтетические сообщения; реальные чаты не читаются автоматически.
