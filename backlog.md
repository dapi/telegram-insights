# Backlog

Источник требований — [PRD](docs/prd.md). Код и личные данные пока не
переносились.

## 1. Самостоятельное приложение

- [ ] Перенести исходный код `tgcli` с сохранением истории Git в этот
      репозиторий и отделить имя CLI, конфигурацию, Telegram-сессию,
      хранилище и службу. Действующий `tgcli` оставить работоспособным.
- [ ] Реализовать PostgreSQL как основное хранилище Telegram Insights;
      миграции и тесты выполнять на синтетических сообщениях.
- [ ] Сделать наблюдаемый статус архива по каждому чату и аккаунту.

## 2. Полнота архива

- [ ] Принимать новые сообщения независимо от исторической дозагрузки.
- [ ] При первом запуске создавать задачи для всех доступных облачных
      чатов на последние 14 суток, обрабатывать новые страницы раньше
      старых и справедливо обходить чаты порциями.
- [ ] Сделать постоянные checkpoint, идемпотентную запись, восстановление
      пропусков после офлайна и добавление новых чатов.
- [ ] Ограничивать запросы истории глобально; обрабатывать `FLOOD_WAIT`
      ожиданием и адаптивным снижением темпа.
- [ ] Проверить на синтетическом аккаунте охват, повтор страниц, рестарт,
      частичные ответы, ошибки доступа и паузу из-за лимита.

## 3. Поиск и первый результат

- [ ] Реализовать внутренний [контракт](docs/postgresql-source.md),
      поисковый индекс, pgvector и checkpoint индексатора.
- [ ] Реализовать межчатовый поиск с проверяемыми ссылками на архив.
- [ ] Реализовать локальный Markdown-черновик [ежедневной сводки](docs/daily-digest.md)
      и отображение неполного покрытия.
- [ ] Оценить качество на сообщениях, разрешённых Данилом для проверки.
      До такого поручения реальные чаты не читать.
- [ ] Отдельно решить расписание, доставку и операционное наблюдение.
