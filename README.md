# Telegram Insights

Приватный проект для поиска, ответов по нескольким перепискам и регулярных
сводок по личному Telegram Данила. Планируемое основное хранилище tgcli —
PostgreSQL; этот проект будет владеть аналитической схемой с pgvector в той же
СУБД.

## Текущий этап

Зафиксированы [архитектура](docs/architecture.md),
[контракт чтения PostgreSQL](docs/postgresql-source.md) и
[первый результат — ежедневная сводка](docs/daily-digest.md). Исполняемого
индексатора и генератора пока нет. Реальные чаты не читались и не переносились.

## Границы

| Владелец | Ответственность |
| --- | --- |
| `~/code/tgcli` | Telegram, основной PostgreSQL-архив и представление для чтения |
| Этот репозиторий | Индексация, поиск, сборка ответов и сводок, оценка качества |
| `~/code/brandymint/infra` | PostgreSQL, pgvector, доступ и резервирование |
| `~/code/personal-ops` | Реестр и состояние фоновых заданий |

Следующие шаги и условия готовности записаны в [backlog](backlog.md).
