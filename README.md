# Telegram Insights

Приватный проект для поиска, ответов по нескольким перепискам и регулярных
сводок по личному Telegram Данила. Исходные сообщения остаются в tgcli;
OpenViking хранит производный поисковый индекс.

## Текущий этап

Зафиксированы [архитектура](docs/architecture.md),
[контракт источника](docs/tgcli-feed.md) и
[первый результат — ежедневная сводка](docs/daily-digest.md). Исполняемого
индексатора и генератора пока нет. Реальные чаты не читались и не передавались
в OpenViking.

## Границы

| Владелец | Ответственность |
| --- | --- |
| `~/code/tgcli` | Telegram, точный архив, постраничная выдача новых записей |
| Этот репозиторий | Индексация, поиск, сборка ответов и сводок, оценка качества |
| `~/code/brandymint/infra` | Развёрнутый OpenViking и модельный маршрут |
| `~/code/personal-ops` | Реестр и состояние фоновых заданий |

Следующие шаги и условия готовности записаны в [backlog](backlog.md).
